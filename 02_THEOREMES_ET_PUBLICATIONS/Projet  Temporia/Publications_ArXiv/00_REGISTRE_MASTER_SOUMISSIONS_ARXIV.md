## 🛠️ Guide Pas-à-Pas pour la Soumission sur arXiv.org

1. **Connexion :** Rends-toi sur [https://arxiv.org/submit](https://arxiv.org/submit) avec ton compte arXiv.
2. **Nouvelle Soumission :** Clique sur *« Start new submission »*.
3. **Licence :** Sélectionne l'option : **`arXiv.org perpetual non-exclusive license`**.
4. **Téléversement des Fichiers (Files Upload) :**
   - Ouvre le sous-dossier de l'article souhaité dans `Publications_ArXiv/`.
   - Téléverse directement le fichier `package.tar.gz` (arXiv le décompresse automatiquement).
   - Clique sur *« Auto-detect / Check files »* : arXiv compile automatiquement `main.tex` en PDF !
5. **Métadonnées (Metadata) :**
   - Ouvre le `README_SOUMISSION.md` du dossier correspondant.
   - Copie-colle le **Title**, les **Authors** (`Christian Duguay, Alix`), la **Primary Category** et l'**Abstract** sans retouche.
6. **Prévisualisation & Dépôt :** Vérifie le PDF compilé par le serveur arXiv, puis clique sur *« Submit »*.
