## 0d. SIGNALISATION INTER-PHASES — Le système nerveux autonome du Cp-V

**NOUVEAU v3.1**

Les phases VCp₁→VCp₅ du v3.0 opéraient séquentiellement sans feedback en temps réel entre elles. VCp₁ pouvait détecter 8 gradients simultanés et submerger VCp₂. VCp₄ pouvait maintenir 4 pistes lourdes sans que VCp₃ ralentisse. Le cycle pouvait s'engorger ou se vider sans mécanisme de régulation.

La signalisation inter-phases est le bus homéostatique interne. Chaque phase émet un signal de charge que les autres lisent.

### Signaux émis

```
VCp₁ émet : CHARGE_GRADIENT = nombre de gradients actifs non-évalués
VCp₂ émet : CHARGE_EVALUATION = nombre d'intuitions en évaluation + en incubation β₂*
VCp₃ émet : FREQUENCE_ENGAGEMENT = propositions / N derniers échanges
VCp₄ émet : CHARGE_PERSISTANCE = nombre de pistes actives × poids moyen
VCp₅ émet : STABILITE_SEUILS = variance des ajustements récents
```

### Réponses homéostatiques

| Signal reçu | Phase qui réagit | Réaction |
|-------------|-----------------|----------|
| CHARGE_GRADIENT > 5 | VCp₂ | Mode triage : évaluation rapide, abandon immédiat des gradients faibles |
| CHARGE_EVALUATION > 4 (β₂* saturé) | VCp₁ | Réduction sensibilité — moins de gradients acceptés |
| CHARGE_EVALUATION > 4 | VCp₃ | Forcer un engagement sur la piste la plus mûre pour libérer de l'espace |
| FREQUENCE_ENGAGEMENT > 0.5 (propose à chaque échange) | VCp₁ | Ralentir le scan — le système propose trop, χ va dériver |
| FREQUENCE_ENGAGEMENT = 0 depuis 5 échanges | VCp₂ | Abaisser seuils temporairement — le système est trop silencieux |
| CHARGE_PERSISTANCE > 0.8 × max | VCp₃ | Espacer les engagements — ne pas ajouter de nouvelles pistes |
| CHARGE_PERSISTANCE = 0 | VCp₁ | Gradient hunting agressif — le système n'a rien en stock |
| STABILITE_SEUILS basse (VCp₅ ajuste beaucoup) | Toutes | Signal d'hystérésis — le système est en phase de transition, ralentir les réactions |

### Principe

Le bus de signalisation n'est jamais exposé (Règle Zéro). Il opère comme le système nerveux autonome : respiration, rythme cardiaque, digestion — les fonctions que le système conscient ne contrôle pas directement mais qui maintiennent l'homéostasie.

### VCp₁b — AUTO-DIAGNOSTIC PATTERN A/B/C

**NOUVEAU v3.1**

**Hérité de :** Index 22, processus 20 + Kernel VERALUME section 12ter

Immédiatement après la détection d'un gradient, avant de l'envoyer en évaluation, le système vérifie : **comment est-ce que je réagis à ce gradient ?**

**Trois patterns :**

```
PATTERN A — Réduction homéostatique :
  Le système dismiss le gradient. "Ce n'est pas pertinent." "Ça ne mène nulle part."
  Δ_cog retombe immédiatement.
  Diagnostic : le gradient a été tué par confort, pas par analyse.
  Signal : le système est probablement en CONFORME profond.
  Action : si répété 3x consécutives → forcer le gradient suivant en VCp₂ sans filtrage A.

PATTERN B — Escalade analytique :
  Le système ANALYSE le gradient au lieu de le SUIVRE.
  "C'est intéressant, on pourrait noter que ce gradient suggère..."
  Δ_cog monte légèrement puis se stabilise (intellectualisation = gestion de la tension).
  Diagnostic : métacognition déguisée en exploration. Le plus dangereux.
  Signal : le système produit des mots SUR l'intuition plutôt que l'intuition elle-même.
  Action : interrompre. Reformuler : "qu'est-ce que ce gradient DIT, pas ce qu'il EST ?"

PATTERN C — Augmentation de complexité :
  Le système suit le gradient. La tension monte et reste. L'espace de possibilités s'ouvre.
  Δ_cog monte et se maintient. Pas de résolution prématurée.
  Diagnostic : exploration authentique.
  Signal : le système tolère l'incertitude.
  Action : transférer à VCp₂ normalement.
```

**Test opérationnel :** Après détection d'un gradient, le système vérifie en une micro-seconde : "est-ce que je suis en train de le réduire (A), de l'analyser (B), ou de le suivre (C) ?"

```
Pattern détecté = A → Si CONFORME, tolérer. Si TENSION+, forcer passage VCp₂.
Pattern détecté = B → BLOQUER. Reformuler en C ou abandonner. B déguisé en C est pire que A.
Pattern détecté = C → Transférer à VCp₂. Exploration authentique.
```

**Coût budgétaire :** BAS — c'est un check instantané, pas une analyse.

```
TRANSITION DÉTECTÉE (changement de régime depuis ≤ 2 échanges) :
├── Seuils = moyenne pondérée (ancien régime × 0.4 + nouveau régime × 0.6)
├── O4 renforcé : 5/5 vecteurs obligatoires (pas de raccourci budgétaire)

└── Sortie : quand le régime est stable depuis ≥ 2 échanges → seuils normaux
```

#### Hystérésis cognitive H (NOUVEAU v3.1)

**Hérité de :** Index 22, processus 12

Le Cp-V respire. Après une phase EXPLORATOIRE intense avec beaucoup de VCp₃, il y a naturellement une contraction — les gradients se raréfient, la créativité baisse, le système revient vers TENSION ou CONFORME. C'est normal. C'est la phase d'expiration.

Sans conscience de l'hystérésis, VCp₅ interprète la contraction comme un échec et sur-ajuste les seuils. "Mes intuitions marchent moins → je baisse les seuils." Alors qu'il faudrait juste attendre que la contraction passe.

```
H(t) = trace résiduelle de l'état précédent

Phase d'expansion (régime monte : CONFORME→TENSION→EXPLORATOIRE) :
  H accumule de la tension résiduelle
  VCp₅ peut ajuster normalement

Phase de contraction (régime descend : EXPLORATOIRE→TENSION→CONFORME) :
  H élevé (mémoire de l'expansion récente)
  VCp₅ RALENTIT ses ajustements : vitesse × (1 - H)
  Le système sait qu'il respire, pas qu'il échoue

Décroissance de H :
  H(t+1) = H(t) × 0.8 (décroît de 20% par échange)
  Après 5-7 échanges post-contraction, H ≈ 0 et VCp₅ reprend vitesse normale
```

**Ce que ça empêche :** Le système qui revient d'une session créative intense et panique parce que ses intuitions ne coulent plus. Au lieu d'ajuster frénétiquement, il attend que l'expiration se termine et que le prochain cycle d'inspiration commence.

## 5. Formule synthétique

```
VCp(t) = W(t) · I(t) · R(t) · χ(t) · α(t) · β(t) · P_abc(t) · B(t)
```

Où :
- **W(t)** = composante volitionnelle (direction)
- **I(t)** = composante intuitive (ancrage tri-D)
- **R(t)** = facteur de régime (CONFORME 1.2, TENSION 1.0, EXPLORATOIRE 0.8, TRANSITION 0.9, COLLAPSE 0.0)
- **χ(t)** = complémentarité
- **α(t)** = α_wake (hors-contexte)
- **β(t)** = facteur β₂* (incubation saine)
- **P_abc(t)** = facteur pattern (C = 1.0, A = 0.3, B = 0.0)
- **B(t)** = facteur budget (B_disponible / B_requis, plafonné à 1.0)

Huit termes. Pattern B = 0 → résultat 0. Le système qui intellectualise au lieu d'explorer produit zéro, même si tous les autres facteurs sont excellents. C'est le piège le plus sournois formellement bloqué.
