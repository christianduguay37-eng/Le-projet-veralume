## Statut de saturation — NON ATTEINTE (correction importante)

Erreur écartée : on ne peut PAS déclarer la saturation à partir de cas qu'on choisit
soi-même, car le choix peut éviter les cas qui feraient craquer la structure (biais
de confirmation d'échantillonnage). La saturation se TRAVAILLE : il faut chercher
activement le CONTRE-EXEMPLE (un cas d'exclusion qui ne rentre dans aucun mode), pas
l'exemple qui confirme.

État réel : la structure (6 modes + méta-mode + effacement) a absorbé tous les cas
testés, MAIS :
- l'échantillon n'est PAS assez diversifié (concentré sur religieux/doctrinal +
  un peu de science ; manquent : sociétés sans écriture, occultations contemporaines
  non-religieuses, matrices mal couvertes — Afrique, Océanie, précolombien
  au-delà du maya) ;
- chaque fois qu'on a cherché dans une zone NON couverte (le mythe-comme-régime),
  on a trouvé du NEUF (le méta-mode) → preuve que ce n'est pas saturé.

Donc D = « structure robuste à ce stade », PAS « saturé/fermé ». La fermeture
demande : diversifier l'échantillon + chasser le contre-exemple. Christian (ou un
tiers non-biaisé) doit pouvoir envoyer chercher dans les angles morts de
l'échantillon — Claude ne peut pas être seul juge de la saturation puisqu'il dirige
la recherche et a un biais.
